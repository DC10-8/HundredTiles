# 324タイル開発状況（未完成・ゲーム内では未対応）

18×18の標準サイズタイルを対象とする開発基盤です。現在のインストール済みDLLは100タイル版です。このソースを324タイル完成版として配布・導入することはできません。

## 実装・検査済みの基盤

Core/MapLayout.cs: 寸法、境界、100→324の購入状態・地形・水流・多チャンネル配列移行。新セルの水道供給や水量を捏造しません。追加地形の辺複製は暫定的な初期化です。
Core/PackedObjectPosition.cs: 明示的に324のレイアウトを渡した場合に、正側の拡張座標コード98303まで扱うオーバーロードを追加。既存100タイルのAPIは変更しません。
Checks/MapLayoutChecks.cs: 324区画、旧100区画の順序・開始位置、地形全サンプル、遠端の樹木等の座標表現、サービス・水道セル、水量・汚染・速度・水流フレームの保持を単体検査しました。既存100タイルの検査も通過しました。
