# 324タイルの実装・検証記録（324 Beta）

18×18の標準サイズタイルへ拡張する324ベータ版の記録です。確認済みゲーム版・MOD版の都市ランタイムへ対応します。過去の未完了・有効化停止の記述は、その日付時点の試験経過として残しています。現在の配布手順はRelease-324-Beta.ja.mdを参照してください。

世界座標の下限-8640mを維持し、正のX/Zへ広げます。上限25920m、幅34560m、面積1194.3936km²。現在の100タイルに224タイルを追加します。

## 最新の確認状況（2026年10月17日）

以下の日付付き記録は試験の経過です。乗降・新設外部接続・UnifiedUIについての過去の未確認記述は、次の追加検証で更新しました。試験専用の起動バイパスを使わない通常324ベータ版の起動・保存・別プロセス再ロードも通過しました。

### 隔離都市全体の100→324移行（2026年10月15日）

### 描画比較と都市Undo（2026年10月15日追記）

人口65万人はユーザーが指定した検証用都市の目標人口です。既存65万人都市の提供待ちではありません。ゲームの実際の建物・世帯・市民を持つ都市を段階的に生成し、交通・供給・負荷を検査する作業が残っています。小規模な隔離都市の結果を大規模都市の結果として扱いません。

## 再現する検査

通常100の純粋ロジック検査に加え、以下で324の寸法・移行・保存検査を実行できます。

```powershell
dotnet run --project Checks -c Release -p:HundredTilesMapProfile=324
```

実ゲームの検証には購入済みゲームの正しいバージョンのアセンブリと、専用隔離環境が必要です。ゲームファイル・都市セーブ・プライベート検証ログは公開ソースに含みません。
試作の隔離環境を作成・復元する補助スクリプトは `IntegrationGame/Prepare-324Trial.ps1` です。先に通常の `Prepare.ps1` で専用ゲームを準備する必要があります。補助スクリプトは元のMODフォルダーをバックアップして、復元時にも試作フォルダーを削除せず保持します。進行中のCitiesプロセスがあれば変更を拒否します。
このブランチの既存リリース用ハッシュ一覧は、公開済み100タイル版の成果物を指します。324開発ビルドと一致するという表明ではありません。324のリリースDLL・リリース用ハッシュ一覧はまだ作成していません。

## 遠端路面の境界フック修正（2026年10月15日）

遠端の道路・線路の路面が欠ける原因は、`BoundaryHooks.DetailCell` が100タイルの最大詳細セル4799を固定使用していたことでした。324タイルのセル8563/8335を4799へ切り詰め、正しく生成された遠端の詳細路面を取得できませんでした。最大セルを使用中の寸法から計算します。100版は4799、324版は8639です。高さの最終頂点と路面セルの上限を混同しません。

修正後の隔離実ゲームで、保存済み遠端の道路・線路を別プロセスで読み込み、道路の切り取り値255・舗装値255、線路の切り取り値175を確認しました。GPU側の道路・線路の路面テクスチャにも対応するマスクが反映され、道路の近接画像ではアスファルトと歩道が連続して表示されました。これは今回の平坦な遠端試験区画に対する結果であり、全ネットワーク・全LODの確認ではありません。
