# 外部接続からの需要に依存しない通過交通

オプションの「外部の通過交通」で、自動発生を切り替えたり、「車・列車の発生を今すぐ依頼」を実行できます。自動発生は都市読み込み時と建物数の増加時に少量の発生を依頼します。実行間隔は最低1024シミュレーションフレーム、1回あたり道路・鉄道それぞれ最大1件です。入居者や旅客需要を変更する機能ではありません。

ゲームに登録された外部接続から、流入可能な接続と別の流出可能な接続を同じ交通種別で選び、標準のOutsideConnectionAI.StartConnectionTransferにDummyCar/DummyTrainを渡します。車両の経路探索、通行方向、車両上限、廃棄はゲーム本来の処理に従います。道路・鉄道の外部接続は同じネットワークで通行可能にしてください。片端だけでは通過交通の行き先が足りません。

需要なしでも発生を依頼しますが、経路が存在しない場合や車両上限に達した場合まで到着を保証する機能ではありません。生成された通過列車は旅客駅に停車する旅客サービスを追加しません。住宅への入居を保証する機能でもありません。

都市以外の画面やエディタでは実行しません。外部接続の属性、セーブ形式、中核ゲームのパッチ対象は追加・変更していません。設定はHundredTiles.outside-traffic.txtに保存されます。

隔離実ゲーム検証: 8回の波で計16件を依頼し、通過用の市民インスタンス9件と列車車両8件の追加を確認しました。15秒後には都市全体で通過用道路車両341台・列車車両4台のSpawned状態を確認しました。この総数には元から存在する通過交通も含まれます。新規依頼車両すべての到着や駅の停車は検証していません。既存コピーの再ロードと入力セーブのハッシュ不変も確認しました。終了時のUnifiedUI/Move It例外は引き続き残っています。
