# Stage17: 樹木・Propの描画・検索と境界

完成版ではありません。有効化は停止中です。

ゲームDLL全体のTreeInstance/PropInstanceの生short座標読み出し10メソッドを監査しました。Position取得2個、グリッド挿入・削除4個、描画更新2個、保存2個です。描画更新へ復元処理を追加し、全10個に専用フックまたは保存投影を接続しています。監査結果はreports/packed-axis-reads.csvです。

樹木・Propの35個の直接グリッド参照処理へ、検索範囲と行幅の変換を接続しました。森林・火災・落雷・災害・公園移動・塗装・削除・地形更新を含みます。6個の描画グループ処理の分割を50×50グループへ変更し、全300/600セルが重複・欠落なく担当されることを確認しました。

樹木・Propのブラシと地区の樹木除去ブラシでは、幅を拡張すると「幅/2」で原点まで動くことを確認しました。幅は拡張し、原点に使う20個のローカル読み出しだけを元の値へ固定しています。実ILの計算を実行して元の135/270セル原点を確認しました。

TerrainManager.RayCastEdgeの外周高さ参照を1201×1201へ拡張しました。世界原点は540セルのままです。最終行1200×1201と最終頂点1201×1201−1を確認しました。CameraController.ClampCameraPositionに−8640から10560mの非対称範囲を設定するフックを追加しました。

実ゲームDLLをロードして430個の導入先を照合しました。現カタログは386メソッド、1788命令です。専用フックはカタログの命令数に含みません。通常カメラとCinematicCameraの範囲フックも実ゲームのUnity Vector3/Mathf型を使ってCLRで実行し、拡張端と高さの維持を確認しました。ゲームプロセスは実行していません。

Verify.ps1全体が成功しました。記録はreports/stage17-verification.log、カメラを含む導入入口の最新の単独検証はreports/stage17-runtime-connections.logです。
