# HundredTiles 1.0 完成記録

標準サイズの1,920mタイルで10×10、最大100タイルの通常都市向けMODを実装し、実ゲームの保存・別プロセスでの再ロードまで検証しました。

## 完成した範囲

- 地形・水流・所有・購入、道路・建物・区画・樹木・プロップ、地区・公園、自然資源、車両・市民の検索と描画を拡張。
- 電気・水道は508×508、サービス資源は500×500×35種類。保存・復元、全域更新と供給を接続。
- 描画グループ、通常・シネマティックカメラ、操作境界、地形編集、詳細地形の描画テクスチャを拡張。
- 地形・水流・所有・資源・地区・樹木・プロップ・電気・水道・サービス資源を都市セーブへ格納。凍結した標準投影、分割保存、欠落・混在・破損拒否と失敗時の巻き戻しを実装。
- IUserModとHarmonyHelperによる通常導入入口、対応版・競合の検査、再起動による無効化、配布ZIPと導入スクリプトを用意。

405個の実ゲームメソッドに1901個の検査済み変更。導入対象456メソッド、51フック署名、39フィールド接続。通常都市向けのcity-runtimeカタログで有効化しています。

## 実ゲームで確認したこと

Windows Steam版1.21.1-f9-steam-winの専用コピー・プロファイルで実施しました。既存都市とユーザー設定は変更していません。

- 標準マップからの新規都市と拡張配列の初期化。
- 最初の9区画を検証用に所有済みとし、残り91区画は本体の購入処理で取得。100区画と詳細地形を確認。
- 追加領域で造成し、本体APIで道路・樹木・プロップ・地区・風力施設・配管を作成。
- 本体の供給APIと更新処理による電気・水道の外周への伝播。実車両経路探索の成功。
- 本体の地形編集ブラシと1442401頂点のバックアップ。
- サービス資源の全256フェーズ・25万セル更新、追加隅の照会と500×500 GPUテクスチャ。
- 配布用MOD入口で都市を保存し、ゲームを終了後、別プロセスで再ロードして各値・オブジェクト・供給・経路を照合。
- 追加地点のCPU/GPU高さが80mで一致。境界の霧を抑え、天候の霧を保った通常カメラと近距離の画面で地形・道路・設備・樹木・プロップを確認。
- 全自動検証、ZIPからの導入、旧版バックアップ、破損一覧の書き込み前拒否。

## 配布と対応範囲

配布物はartifacts/HundredTiles-1.0.zip。Harmonyが必要です。導入方法はREADME.ja.md、詳細と証拠ファイル名はdocs/Release-1.0.ja.mdに記載しています。

対応範囲は対象版の通常都市です。エディター・シナリオ、他の空間拡張MODとの併用は対象外です。オブジェクト総数の上限は標準のまま、追加外周の外部接続は自動生成しません。人口を持つ大都市での長時間運行・性能測定は今回の検証に含みません。
