# 樹木・Propのゲーム側フックと保存投影

位置getter/setterの4フック、Initialize/Finalizeの4 IL変換、
標準Serializeへの2つの投影フックを追加しました。自動適用はしていません。
TreeManager.AwakeとPropManager.Awakeの配列確保もレビュー済み計画に加え、
計画は233メソッド・998編集になりました。専用変換の件数はこの数字に含みません。

構造体のコピーでも追加座標を保持するため、対象ゲームのFlags enumで
未定義の0x1000/0x2000をX/Zの追加領域マーカーとして使用します。
他のflagsと座標の刻みを保持し、内側への移動時はマーカーを解除します。
Asset Editorでは既存のPosition処理に委譲します。
このビットを使う他MODとの競合確認は未実装です。

グリッド座標の540/270倍の係数と32768の原点は保持し、
上限を599/299、行幅を600/300へ拡張します。
Finalizeの描画グループ比率は50/600と50/300へ接続しています。
Positionを経由せずm_posX/Zを読む別のメソッドはまだ接続が必要です。

ObjectSaveBridgeは型付きバッファの複製、標準保存への位置投影とマーカー除去、
拡張保存の検証、復元バッファ・検索リストの作成、既存配列への反映を実装します。
復元はPrefab再割り当てと読み込み時の火災flagsを保持します。
Prepareではライブ配列を変えず、Commitでは配列の参照を保持します。
呼び出し元がロード段階を維持し、地区内の樹木・Prop数と描画が再集計される前に
Commitする必要があります。現在のRuntimeSaveBridgeにはまだ組み込んでいません。
保存ルートの公開・巻き戻しとロード順序の統合が残っています。

検証内容:

- 72,817座標の位置フック、構造体コピー、既存flags、内側への移動、無効入力。
- 実ゲームILの4グリッド変換。Initializeの座標部分を全360000/90000セルで実行。
- Asset Editorの旧座標と不正なILの拒否。
- 実ゲームILの2保存バッファ投影。火災リストのバッファを除外し、例外境界を保持。
- 327678個の配置済み実体の保存投影と検索リスト復元、重複・欠落検査、Prefab/火災flags維持。

Unity上の動作は未検証です。Initialize/Finalizeのリンク操作全体を実ゲームで
実行したという意味ではありません。CanActivateはfalseのままで、完成版ではありません。
