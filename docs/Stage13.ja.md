# 電気・水道の拡張キューとグリッド接続

標準の電気・水道グリッドは256×256、セル幅38.25mで、
キューのX/Zはbyteです。配列だけ広げると255を超える座標が折り返すため、
ushortキューを使用する処理が必要です。

UtilitiesはMITライセンスの81 Tiles 2、コミット
04fa96241fab752b5d90a47a311246613e1af66dの供給処理を移植しました。
帰属とライセンスはUtilities/UPSTREAM.mdとUPSTREAM-LICENSE.txtに保存しています。
外部参照用チェックアウトはresearchにあり、配布対象ではありません。

グリッドを508×508、原点を231セルとしました。
旧256×256は103セルずらして移行し、世界座標は変わりません。
グリッドの範囲は-8835.75m～10595.25mで、100タイルの範囲を覆います。
508行を128フェーズで1回ずつ更新することを検証しています。

電気・水道のSimulationStepImplと電気UpdateGridの接続仕様を追加しました。
キューをushortへ拡張した処理、道路・建物の300幅への参照を含みます。
対象ゲームのprivateフィールド名と型をSpecificationsで確認します。

レビュー済み変換は254メソッド・1131編集です。
供給グリッド・テクスチャ確保、電気・水・下水・暖房の問い合わせ、
水道UpdateGrid、表示テクスチャとシェーダー座標を追加しました。
水道UpdateGridの255は座標上限だけを変え、伝導率の255を保持しています。
水道表示の2048は原点に合わせ3696へ変え、相対位置符号化の128は保持しています。

この段階では保存・ロードの基盤へ供給セル・拡張キューを統合していません。
標準serializerが拡張配列をそのまま読まないよう投影と読み込み先を接続し、
キュー・進行フェーズ・供給グループを保存してから有効化する必要があります。
Unity上の送電・送水・暖房・表示・保存再ロードは未検証です。
ビルドと座標・配列移行・更新行の検査に成功したことだけを完了扱いにしています。
