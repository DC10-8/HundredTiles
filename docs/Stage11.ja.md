# 樹木・Prop座標と保存形式の基盤

Core/PackedObjectPosition.csは既存short座標の刻み0.263671875mを保持し、
正方向の追加領域を別のマーカーで表現します。ゲームのflagsは変更しません。
旧setterの負方向クランプと丸めを保持し、10560mの排他的上限へ丸めがはみ出すことを防ぎます。
樹木600区画・Prop300区画の一軸検索座標も計算できます。

Core/ObjectPositionCodec.csは樹木262144スロット・Prop65536スロットを
2,293,876バイトで保存する候補形式です。SHA-256、32バイトの外部スナップショット識別値、
標準保存へ投影した位置・flagsの指紋を検証してから復元結果を返します。
Prefabの数値IDはロード時に再割り当てされるため指紋に含めません。
樹木の火災flagsは標準ロードの扱いに合わせて指紋で正規化します。
未使用スロットの位置は標準保存へ投影するときゼロになります。

Checksは旧座標65,536通り、追加座標8,282通り、検索区画の中心、
全327680スロットの保存復元、破損・別スナップショット・標準データ不一致を検査します。

これはゲームに未接続の基盤です。マーカーの実体への保持、Position getter/setter、
生short参照、グリッドの初期化・更新・描画、標準serializerへの投影、
ロード順序と地区内オブジェクト数の再集計、保存セッションへの組み込みが残ります。
CanActivateとレビュー済みパッチ231本・996編集は変更していません。
