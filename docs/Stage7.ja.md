# 第7工程：資源元グリッドの拡張と保存

NaturalResourceManagerの元データを512×512から569×569へ拡張する変換と、
更新処理、参照API、描画座標、専用保存を接続しました。
第6工程で残っていた追加領域の資源保存制限を解消する実装です。
ゲームへのパッチ適用入口はまだなく、CanActivateはfalseです。

## 座標と更新

セル幅33.75mと従来の原点を保ち、323,761セルを確保します。
19,200mを覆うため569セルが必要で、最後のセルが区画境界の外へ3.75m重なります。
所有区画の最大境界は引き続き10560mです。追加セルの初期資源はゼロです。

512固定のビット演算による更新順序を、569行それぞれを2回で更新する
1,138フェーズへ変更します。前半284セル、後半285セルです。
区画キャッシュの書き込み先も10列に対応します。
エディター側の更新フレーム生成も変更します。uintの周回を越えた更新順序の
連続性は保証しておらず、長時間稼働の検証は残ります。

資源の追加・照会、森林近接、汚染・水量・樹木量の照会、更新通知と
テクスチャ更新の上限・ストライドを拡張します。
ResourceWrapperの実ゲームILを使い、World/Grid変換が従来の原点を保つことを
検証します。シェーダーへ渡すマッピングも拡張幅と原点に合わせます。
Unityでの表示確認とTreeManager側の空間範囲の接続は残ります。

## 保存と復元

HundredTiles.Resources.v1に3,889,244バイトの専用データを保存します。
全セルの12フィールド、100区画の10個ずつの集計値を保持します。
SHA-256による破損検査、標準資源データの投影との照合、地形・水流・所有情報との
組み合わせ照合を復元前に行います。

標準シリアライザーには凍結した512×512セルと81区画を渡します。
標準形式が省略する樹木量・肥沃度・変更フラグは比較用投影で正規化し、
専用形式では元の値を保持します。追加領域の非ゼロ資源も保存できます。
旧セーブはscratchへ読み込み、追加セルと追加区画集計をゼロで移行します。
保存失敗時は地形・水流、所有、資源の拡張保存を以前の状態へ戻します。

## 検証と残る作業

2026年10月10日にVerify.ps1の一括検証が成功しました。
Core、Diagnostics、ExperimentalPatch、SaveBridgeのビルドは警告0・エラー0です。

定数変換は108メソッド本体・546変更です。これとは別に資源更新の専用変換、
標準シリアライザー8本体への16箇所のヘルパー注入、ResourceWrapperの2本体への
原点補正を検証します。

実ゲームILを変換した更新順序を実行し、1周期で全323,761セルを重複なく
更新すること、100区画の範囲内へ分類することを確認します。
座標変換も569セルすべてで実行します。モックでは全セルの12フィールドの
往復、追加領域の集計、標準形式で省略される値の復元、破損・欠落・混在データの
拒否と保存失敗時のロールバックを検証します。

これらはゲーム内の動作確認ではありません。建物・道路・地区・サービス・
経路探索の空間グリッド、地形と水面の描画、カメラ、RayCastEdge、
インポート／エディター境界、外部接続、MOD競合検出の作業が残ります。
過去の開発パッケージは第7工程を含まないため、現在のソースを参照してください。
