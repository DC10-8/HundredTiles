# 第4工程：地形の参照・編集処理の接続

標準サイズ10×10への拡張に合わせ、地形・水面の問い合わせと地形編集の
Harmony変換を追加しました。実行中のゲームにはまだ適用していません。

## 実装

- 高さの通常／平滑サンプリング、元地形・最終地形・ブロック高さ、
  水面高さの各オーバーロード、水位・水の有無・水流・岸辺の問い合わせを
  1200セル、1201頂点ストライドへ変更。
- 詳細地形・表面・区画の取得と詳細パッチ設定を10列へ変更。
  タイル内の480セル／481頂点は維持。
- 詳細高さの全域上限を4320から4800へ、RAW表面の固定小数点上限を
  2211839から2457599へ変更。
- 地形編集の再構築とApplyQuadのRAW高さ書き込みを拡張配列へ接続。
  再構築処理のパッチ上限はレビューしたIL命令96、112だけを8から9へ変更。
  同じ値を持つフラグ、シフト量、編集作業領域の余白は維持。
- オーバーロードをメタデータトークンと元ILのSHA-256で個別に固定。
  他のメソッドへ委譲するだけのオーバーロードは変換対象外。

旧都市の座標を維持するため、浮動小数点の原点540、2160、8640と
原点計算に使う17280は変更していません。拡張範囲は両軸とも
−8640mから10560mです。

## 検証

レビュー済みゲームアセンブリに対する変換計画は合計61メソッド本体、
323変更です。元アセンブリを編集せず、実際のILをHarmony命令に変換して
全変更、未変更命令、分岐ラベル、例外マーカー、入力の非破壊性を検証します。
パッチ上限とストライド、対象オーバーロード、旧形式インポートの対象外指定も
検査します。保存・復元の8箇所のヘルパー挿入は引き続き別途検証します。

これらは静的変換とモックでの検証です。Unity上の地形編集、描画、
水流、建設、保存再ロードの動作確認を意味しません。

## 残る接続

1. GameAreaManagerの購入・所有情報保存・開始区画・境界表示。
2. RayCastの非対称なワールド境界、外縁描画、カメラ、ツールの境界。
3. 旧サイズの高さマップインポート／エクスポート用アダプター。
4. 資源、道路、建物、地区、サービス、経路探索等の空間グリッド。
5. MOD競合検出とゲーム内試験。

旧高さマップの入力形式を単純に1201へ置き換えると入力配列の範囲外を読むため、
今回の変換対象には含めていません。この未接続処理を呼ぶ状態での有効化はできません。
`CanActivate`は引き続きfalseで、配布用・プレイ用の完成MODではありません。
