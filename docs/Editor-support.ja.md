# エディタ併用対応（2026-10-13）

HundredTilesを有効にしたまま、アセットエディタ等を通常サイズで開くための起動用途設定を追加しました。

## 操作

1. オプション → HundredTiles → 「起動用途」で「エディタ（通常サイズ）」を選びます。
2. ゲームを完全に終了し、再起動してエディタを開きます。MODの無効化は不要です。
3. 都市を遊ぶ前に「都市（100タイル）」へ戻し、再度ゲームを再起動します。

選択の変更は次回起動に反映されます。選択内容と日英文言は保持されます。言語変更によって用途は変わりません。エディタ用途で都市を読み込もうとした場合、または都市用途でエディタを開こうとした場合は、設定変更・再起動の案内を表示し、読み込み前に停止します。エディタでは100タイル開放・自然生成を実行できません。初期値は従来と同じ都市用途です。

## 実装

`StartupProfile` は用途をローカル設定へ保存します。`SessionGate` は起動時の用途を固定し、`LoadingManager.LoadLevel` の先頭で異なる用途の読み込みを拒否します。

都市用途では従来と同じ初期化時点で都市用パッチを適用します。エディタ用途では都市用の地形・水道・電力・空間グリッド・描画・保存パッチを登録しません。都市用パッチの起動に失敗した場合は、通常サイズで都市の読み込みを続行せず停止します。既存のゲーム版照合、互換性照合、未知の競合による保存拒否は維持しています。

`Starter.Awake` はメインメニューの前にシミュレーション管理クラスを登録・初期化します。そのため読み込みボタンを押した時点で用途を自動切り替えする方式は採用しません。初期化済み配列の書き換えや他MODの管理クラス参照の交換も行いません。

旧 `BoundaryHooks.CityMode` の常時読み込みフックは削除しました。都市種別の検査は `SessionGate` から引き続き行います。Harmonyではキャンセル後もvoidのprefixが呼ばれ得るため、旧フックを残すと案内表示後にエディタ非対応例外が再発するためです。

## 検証範囲

実ゲームの隔離環境で、通常サイズのアセットエディタとAsset Importer画面への到達を確認しました。所有グリッド25要素、地形1081×1081、都市用パッチなし、開放操作の拒否を検査しています。

全MODを残した初回フィクスチャでは、TM:PEのエディタ初期化時に `ExtSegmentEndManager.CalculateCorners` 等の `IndexOutOfRangeException` が発生しました。エディタの基準検証はHarmony・HundredTiles・HyperLoad・LoadTimeRemainingで行います。任意の交通・ネットワーク拡張MODのエディタ互換性まで保証するものではありません。

アセットの作成・書き出し・再インポート、マップ／テーマ／シナリオエディタの個別実操作は今回の確認範囲外です。シナリオ都市の100タイル化には対応しません。

## 最終版の確認結果

- エディタ用途: 2026-10-13、実アセットエディタとAsset Importer画面への到達。通常グリッド25要素・1081×1081、都市用パッチなし。都市読み込みは設定変更と再起動の案内で拒否。
- 都市用途: 実環境の485ターゲット（別途用途ゲート1件）を適用し、隔離都市コピーを実SavePanelで保存。別プロセスで再ロードし、追加領域の電気・水道・道路・建物・地区・地形・サービス資源と保存センチネルを確認。未知のパッチ競合時の保存拒否、都市からエディタへの読み込み拒否も合格。
- 保存・再ロードしたコピーのSHA-256: `D2B5F399B170F1DB764E784E57907FBDC5CD0ABCF54C8E1A37CC8FCDAE49D766`。再ロード後も入力ファイルのハッシュは不変。元の隔離検証都市は `8F0CE536560AD8279F250D2702A2769257C8C2041E74D4EC7E6F2BB212917935` のまま。
- 都市・エディタ双方で実オプションの用途選択を変更し、設定保存・日英表示・選択の保持・実行中のパッチ不変を確認。都市での100タイル開放と重複クリック検査も合格。
- Releaseビルド0警告・0エラー。二つの異なる場所のクリーンソースから同じ6DLLを再現し、配布DLLと照合。
- 多数のMODを含む都市の終了時には、従来のUnifiedUI・Move Itの例外が残る。今回、それらのMODの修正や大規模都市・長時間運用・全構成での安全性確認は行っていない。
