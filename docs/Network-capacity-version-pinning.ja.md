今回の復旧は、新版2本を外部へバックアップしたうえで、上表の検証済み2本へ戻す方法で行いました。実導入先の全対象メソッド照合と、324本体の配布ハッシュとの一致を確認しました。新版への対応を完了したという意味ではありません。都市セーブは読み込み・変更していません。

## 既に検証済み版を手元に保存している場合

ゲームを終了し、リポジトリのRestore-ReviewedNetworkCapacity.ps1へModDirectory（現在のMODフォルダー）とReviewedDirectory（上表の2本を保存したフォルダー）を指定します。スクリプトは両方の入力を照合し、現在の2本をバックアップしてから復元します。途中で失敗すれば元の組み合わせへ戻します。バックアップ場所を出力します。

このスクリプトは旧版をダウンロードせず、任意の版を承認しません。検証済み2本がない場合は、独自にDLLを書き換えたり照合を外したりせず、対応版の確認が必要です。Steamの更新やファイル検証で置換される場合があります。
