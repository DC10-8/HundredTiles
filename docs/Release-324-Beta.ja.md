# HundredTiles 324 Beta

Cities: Skylines 1の標準サイズ18×18区画を使う324タイル版です。確認したゲームは1.21.1-f9です。都市モードの通常ランタイムとして動作し、試験専用の起動バイパスは必要ありません。100版とは同時に導入しません。

## 導入・操作

1. 都市ファイルをゲーム外へバックアップし、ゲームを終了します。
2. 同梱Install.ps1を実行します。既存のHundredTilesはバックアップしてから同じフォルダーへ置換します。81 Tiles等、別のタイル拡張MODは無効にします。Harmonyが必要です。
3. ゲームを起動しHundredTiles 324 Betaを有効化します。オプションの起動用途を都市（324タイル）にして再起動します。
4. 都市のコピーを読み込み、オプションの全324タイル開放を実行します。日本語／英語はオプションで即時切替できます。100タイルの保存は旧座標を維持して移行します。
5. 324版で保存した都市は324版で読み込みます。100版やバニラへ戻す変換は提供していません。元の100版セーブは残し、別名で保存してください。

地形の都市Undoはオプションから実行できます。エディタを使う場合は起動用途をエディタへ変更してゲームを再起動します。エディタのグリッドは標準サイズです。

## 検証と対応範囲

全324区画の購入、100からの都市全体移行、遠端建設・実設備供給、生成65万人都市の運転と保存・別プロセス再ロード、遠端バスの実乗降、新設道路・線路の外部接続への実到着、都市／エディタUndo、対象3地点×5距離の描画を隔離ゲームで検証しました。詳細と識別ハッシュは同梱の検証記録を参照してください。

確認済みのMOD版だけを対象に厳密な照合を行います。不明なパッチ競合や読み込み失敗を検出すると起動・保存を拒否します。全Workshopアセット・全MOD構成の保証ではありません。65万人都市は生成した負荷用データであり、成熟したプレイヤー都市の検証とは区別しています。

More Network Capacity Renewの未対応アップデートでは起動を拒否します。対応DLLの識別値と復旧の制約は[依存MODの版固定](Network-capacity-version-pinning.ja.md)を参照してください。最新版に自動追従する仕組みではありません。

FPS Booster併用時のBaseUButton.Start照合失敗は、確認済みの初期化処理を厳密に照合する修正版で対応しています。[対応内容と版](FPS-Booster-compatibility.ja.md)を参照してください。

324版はベータです。100版よりメモリ・保存容量・計算量が増えます。検証環境ではゲームのワーキングセットが約29GBに達しました。この値は必要メモリの上限・下限の保証ではありません。重要都市の唯一の保存には使用しないでください。

## ソースからのビルド

購入済みゲームのManagedアセンブリとCitiesHarmonyを用意し、Build.ps1 -MapProfile 324、Package.ps1 -MapProfile 324でビルド・梱包します。ゲーム本体・都市セーブ・検証用IntegrationGame.dllは配布物へ含めません。
