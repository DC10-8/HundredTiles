# More Network Capacity Renew 併用

対象はWorkshop ID 3818403598の、次のハッシュのローカルDLLです。バージョン違いを自動的に許可しません。

- Core: `3E40AF8B9FD02C4FB6E96D29FACDFAF06D8D6110FB32A092ACB3D90B7115DDAF`
- Renew原版: `C4334AD302F232644E147EC6FC2397C0C328EF26A02BCA8E1CE71A5F0183338B`
- Renew互換パッチ版: `83E318E1ED01D4C000EC268A31767EF295A2357814C025DAD6A8E8E631D5C832`

HundredTilesは電気・水道のノード配列と循環キューを65,024件に対応させ、既存のv1保存形式から移行します。循環キューの順序を保持し、不明な容量・破損・容量縮小は拒否します。サービス資源の保存形式は変更しません。

対象Renew DLLは旧Harmony 1.2 APIを参照しています。現行Cities Harmony環境で読み込みエラーを確認したため、ローカルDLLのAPI参照だけを変換するパッチャーを公開しています。Harmony生成1か所とPatch呼び出し16か所を変更します。対象MODの機能を省略する処理ではありません。元のDLLはゲーム外にバックアップします。第三者DLLはHundredTilesの配布物に含めません。

ゲームを終了し、.NET SDK 10.0.401のある環境で実行します。

```powershell
./NetworkRenewPatcher/Apply.ps1 -ModDirectory '<3818403598のフォルダー>' -HarmonyDll '<CitiesHarmony.Harmony.dllのパス>'
```

Steamの更新・整合性確認で互換パッチが戻る可能性があります。未知の更新版はこのパッチでは処理できません。元に戻すには、ゲーム終了後、スクリプトが表示するバックアップを元のDLLパスへコピーします。

既存都市は別名のコピーと外部バックアップで試してください。容量拡張後の都市から容量MODを外す移行は対応範囲外です。大規模都市、長期運用、任意のMOD構成の安全性を保証するものではありません。実ゲーム検証結果は検証記録に別途記載します。


## 2026-10-13更新版への対応

本体1.0.19と、同時に導入されていたRenewラッパーに対応します。

- 更新Core: `067E31563D5B7496E3DEAD4B70B79593E85B405F55BFE2F04BA7ACC2B218B03C`
- 更新Renew原版: `BB664EAC91039216A1BA65C70EC5C5AAD06E50BBA46CFF2F5CCEAD3C742B0E18`
- 更新Renew互換パッチ版: `867BE560EDCFF616E8B737A88CB5F50A51148F866D76F4B038644F611F686A39`

更新ラッパーにも旧Harmony APIへの参照が残っています。Apply.ps1はこの原版ハッシュを判別し、Harmony生成1か所とPatch呼び出し18か所を変換します。更新版はushort/uintを指定したTM:PEの信号処理メソッド検索をすでに実装しているため、それを変更しません。旧版の16か所の変換と信号検索修正も引き続き利用できます。

更新Coreのネットワーク保存サイズの解析、互換性再試行、初期化・診断の変更、および更新ラッパーのRenderManager境界確認等を確認しました。HundredTilesはバイナリのハッシュに応じた別のメソッド照合表を使用し、新旧の照合条件を混在させません。新しいRenderManager.GetInstanceIndex/UpdateInstanceのフックは対象メソッドとラッパーの照合済みパッチメソッドに限って許可します。

新版・旧版のCore/ラッパーの照合検査が合格しました。未変換の新版ラッパーと、承認済みディスクDLLに対してメモリ上のGetNodeReadSizeを変更したフィクスチャは拒否されます。未知の版を許可する処理は追加していません。

第三者のCoreおよびラッパーDLLは公開ソース・HundredTiles配布ZIPには含めません。Steamの更新等で原版へ戻った場合は、ゲームを終了して、対応する版に対してApply.ps1を再実行してください。

実ゲームでは、上記の更新Coreと互換修正ラッパーを含む隔離MOD構成で485対象の適用を確認しました。旧版で作成した隔離都市コピーを読み込み、65,024件のネットワークノードと6種類の電気・水道配列、追加領域の道路・建物・地区・地形・資源、Move It・暖房の検査が合格しました。更新版との併用で実SavePanelから保存し、別プロセスで再ロードできました。入力コピーのSHA-256は `41C758DAF27D9768DF57ECB5FE28B2DBDC1772F0274BB95F6EF5CC365AF1AF63` のままです。小規模な隔離都市での検査であり、大規模都市・他のネットワーク連携MOD・エディタの検証結果ではありません。以前からのUnifiedUI・Move Itの終了時例外は残ります。

二つのクリーンソースの6DLLが一致し、配布DLLと照合しました。旧Renewパッチの生成結果も以前のハッシュと一致します。
