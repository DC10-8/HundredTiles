# 第6工程：購入価格の参照と建設境界

購入価格の計算が100区画の番号を使うようにし、道路・資源集計と
地形平坦度の参照を接続しました。建設可否の所有境界と地形RayCastも
拡張範囲に合わせました。有効化・ゲームへの導入はまだ行っていません。

## 集計の接続

- GameAreaManager.CalculateTilePriceの区画番号を10列へ変更。
  価格係数、価格表の最終項目へのクランプ、価格変更コールバックは維持。
- NetManagerの区画別道路・公共交通カウンターを1050から4200要素へ拡張。
  100区画×42サービス枠。既存のノード再集計・読み出しは前工程で変更した
  GetAreaIndex／GetTileIndexを使います。
- 地形平坦度の余分な2区画オフセットを除去し、パッチ参照を10列へ変更。
  全域平坦度のループと平均の分母を100区画へ変更。
- NaturalResourceManagerの派生区画キャッシュを81から100へ拡張。
  区画別・所有区画・購入可能全域・全資源の集計を10列へ変更。
- 資源更新のキャッシュ書き込みだけを10列へ変更。元データの512×512、
  セル分類係数18、原点とセルサイズ33.75mは維持。

資源キャッシュの標準保存には左上9×9の81要素を渡し、読込時は81要素の
scratchから既存100要素配列へ移行します。保存用投影はスナップショットです。
資源キャッシュ読込が完了していない場合はManager再構築を拒否します。

## 境界

GameAreaManagerの点、半径付き点、四角形の所有判定、ClampPointの
ゲームプレイ用区画番号と座標を接続しました。ClampPointの境界は
−8640mから10560mです。Asset Editorの装飾領域による判定は維持します。

TerrainManager.RayCastのクリッピング矩形は中心(960,960)、幅19200mへ
変更し、高さ参照の上限・ストライドも拡張しました。レビュー済み4箇所の
浮動小数点命令だけを変更し、既存の地形座標原点を保ちます。

## 検証

レビュー済み変換は合計92メソッド本体・470変更です。
保存関連は実ゲームの8メソッド本体で14箇所のヘルパー注入を検証します。
分岐、例外マーカー、未変更命令、元ILハッシュと不正入力拒否も検査します。

モックでは262144個すべての既存資源セルが元の区画へ分類されること、
4200サービス枠に重複がないこと、資源キャッシュの投影・凍結・復元を検査します。

## 資源元グリッドの未接続部分

この工程で拡張したのは派生区画キャッシュです。資源元データは512×512の
旧範囲のままで、追加の行・列には資源集計が生成されません。
追加領域の水量・森林・鉱石等を含む価格はまだゲーム内で正しく計算できません。
追加領域の資源元グリッド、更新・描画と専用保存の実装が必要です。

現段階の保存は追加区画の資源キャッシュに非ゼロデータがあれば拒否します。
対応前のデータを標準保存への投影で切り捨てることはありません。

建設・サービス・地区・経路探索等の空間グリッド、カメラ、外側の
RayCastEdge、その他エディター境界、MOD競合検出も未完了です。
静的変換とモックの検証は、Unity上の価格・建設・表示・保存再ロードの
動作確認を意味しません。CanActivateはfalseを維持しています。
