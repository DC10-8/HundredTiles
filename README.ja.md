# HundredTiles 1.0

**試験公開版です。** 大都市での長時間運転や任意のMOD構成は未検証です。元のセーブを外部へバックアップし、コピーで使用してください。[安全性・再現検証の状況](docs/Safety-and-build.ja.md)に確認済み範囲と未検証事項を記載しています。

Cities: Skylines 1の都市領域を、標準サイズの1,920mタイルで10×10、最大100タイルへ拡張します。領域の幅は19,200m、面積は368.64km²です。元の都市座標を維持し、正のX・Z方向へ1列・1行を追加します。

## 対応環境

Windows版Cities: Skylines 1 **1.21.1-f9-steam-win**を対象とします。ゲームDLLのSHA-256と変更対象のメソッドを照合し、異なるゲーム版や対象メソッドを変更するMODとの競合では適用を停止します。

通常のマップからの新規都市と都市セーブの読み込みに対応します。マップ・アセットエディター、シナリオは非対応です。81 Tilesなど同じ空間管理を変更するMODと併用しないでください。HundredTiles単体ではオブジェクト数の上限は標準のままです。[More Network Capacity Renewの併用手順](docs/Network-capacity-compatibility.ja.md)は対象版へのローカル互換パッチを含みます。

Move It! 2.10.9（2.10.9.41557）には、建物・道路・プロップ・樹木の検索、建物の移動、描画更新の9メソッドへ互換処理を適用します。元の座標原点を維持して配列の幅と検索範囲を拡張します。対象DLLとメソッド本体を照合し、未確認の版への適用を停止します。Move It!本体は同梱しません。

No Utility Networksの確認済み版（1.0.0.0）には、需要ゼロ時に暖房の蓄熱上限までゼロになる問題への互換処理を適用します。MOD自身の初期値100,000を下限として保持し、暖房施設が生産した熱を受け入れられるようにします。熱を自動生成する機能ではありません。施設の稼働・燃料・発電供給は引き続き必要です。

Extra Landscaping Tools（NaturalResourcesBrush.dll、確認済み版1.0.0.0）には、置き換えた地形ツールの6メソッドへ互換処理を適用します。地形編集・バックアップ・取り消し・溝掘りの配列を1201×1201へ対応させ、元の座標原点を保持します。対象DLLと各メソッドのILハッシュを照合します。本体DLLは同梱しません。

Building Control、FreeUtilities、TerrainLink、QuayTools、Custom Zone Mixer、RightOfWay、SimulationGuard、First Person Camera、HyperLoad、PassengerLineBuilderの確認済みDLLには、対象と処理内容を照合した互換処理があります。TerrainLinkの建物・道路検索とRightOfWayの車両検索も拡張範囲へ接続します。未確認の版や未知の競合では適用を停止します。本体は同梱しません。

読み込み時にメタデータの参照番号が変わる構成では、確認済みのディスクDLLから事前に作成した照合値を基準に、起動中メソッドの署名・命令・参照先・定数・ローカル変数・例外処理を照合します。基準DLLをゲーム内で再読み込みしないため、書き換え済みの読み込みキャッシュに影響されません。番号だけの変更は許容し、地形の列幅など処理内容の変更は拒否します。FPS BoosterがOnEnableの先頭へ追加する既知の登録処理は、完全な照合値とBehaviourUpdater DLLの照合を通した場合に許容します。

初めて拡張する都市では、追加19タイルに起伏と森林を自動生成し、元のマップの正のX・Z方向の境界に達している川・水域を追加外周までつなぎます。川床には起伏用の境界補間を適用せず、水位を連続させます。地形と二つの水流バッファをネイティブ水流処理の停止中に更新し、川の途中にも自然水源を配置します。森林は最低スケールでも高さ8m以上の樹種を16m間隔の候補点へ配置します。元の81タイルの地形、追加領域の道路・建物・プロップは維持します。川の経路にこれらの保護物がある場合、その接続は見送り、件数を表示します。追加領域の既存樹木は位置のX・Zを保持し、変更した川床の高さへ追従します。既存の外部接続を保持し、追加外周の外部接続を自動生成する機能は含みません。

追加領域の角に十分な空き陸地がある場合は、蛇行する川も生成します。最外周の水位が海面に固定されるゲームの条件に合わせて、川床と水面が海面の出口まで下る形にします。

追加領域を覆ってしまう標準の境界の霧を抑えます。天候・汚染の霧と元の設定値は保持します。

## 導入

1. ゲームを終了し、[Harmony](https://github.com/boformer/CitiesHarmony)を導入します。
2. `HundredTiles-1.0.zip`を展開します。
3. 展開したフォルダーの`Install.ps1`をPowerShellで実行します。手動の場合は`HundredTiles`フォルダーを`%LOCALAPPDATA%\Colossal Order\Cities_Skylines\Addons\Mods`へコピーします。
4. ゲームのコンテンツマネージャーで`HundredTiles 1.0`を有効化し、**ゲームを再起動**します。

有効化・無効化は再起動で反映されます。動作中の拡張配列から標準の添字計算へ戻すことを避けるため、無効化した際もそのプロセスではパッチを保持します。

人口・マイルストーンによる購入制限を外し、開始時から隣接する未購入区画を最大100区画まで購入できます。通常の購入には費用が必要です。

都市を読み込んだ後、「オプション → HundredTiles 1.0 → 100タイルをすべて開放（無料）」を押すと、費用なしで全区画を一括開放できます。解放完了前に、追加19タイルの海面以下の部分へ現在の海面まで水を入れ、水面の描画データも更新します。一時停止中でも水が流れ込むのを待つ必要はありません。元の81タイル・海面より高い陸地・すでに海面より高い水位は維持します。既に100タイル開放済みの都市でも、同じボタンで海面を初期化できます。処理結果をボタンに表示します。開放状態と水を残すには都市を保存してください。

旧版で自然を生成済みの都市は、ゲームを再起動して都市を読み込み、「オプション → HundredTiles 1.0 → 川の接続を修復して森林を増やす」を押してください。既存の起伏は重ねて生成せず、川の接続・旧版の蛇行する川の全区間の水位を修復し、森林を追加します。修復は都市ごとに1回で、繰り返しても水源・樹木を増やしません。結果の川の接続数・追加樹木数・水源数・見送り件数を表示します。川全体には初期水位を設定し、シミュレーションを再開すると流れ始めます。地形・森林・水源を残すには、修復後に都市を保存してください。

拡張領域に建設した都市はHundredTilesを有効にして読み込んでください。元の都市を残したい場合は、最初の保存時に別名を使用してください。拡張保存では地形・水流・所有・資源・地区・樹木・プロップ・電気・水道・サービス資源のデータをセーブ内に格納します。サービス資源は500×500×35種類、分割保存と照合付きです。

タクシーは購入済み領域でゲーム標準の確率に従って利用できます。住民・観光客の判定をX/Zの拡張範囲へ合わせ、外周40mの呼び出しと観光客の域外目的地を抑止します。タクシーにはAfter Darkの営業所・道路接続と通常の営業条件が必要です。

## 言語切替

「オプション → HundredTiles 1.0」の「言語 / Language」で「日本語」「English」を選択できます。見出し・ボタン・処理中／完了／失敗の表示が即時に切り替わり、言語設定を保存します。言語切替ではタイル解放や自然生成を再実行しません。

## 検証

隔離した実ゲームで、新規都市、100区画取得、追加領域の地形・道路・地区・樹木・プロップ・発電施設・配管、電気と水道の伝播、車両経路探索、都市保存と別プロセスでの再ロードを検証しました。サービス資源の全25万セル更新とGPUテクスチャ、地形のCPU/GPU高さの一致、通常カメラと近距離での実描画も確認しています。

詳細は配布物の`検証記録.ja.md`を参照してください。開発ソースでは`docs/Release-1.0.ja.md`に記録しています。人口を持つ大都市での長時間運行・性能測定は今回の検証に含みません。

## 開発

`.\Verify.ps1`で移行・保存・破損拒否・実ゲームIL変換と接続の検査を実行します。実ゲーム検証は`IntegrationGame`に分離しています。配布物にゲーム本体やこの検証入口は同梱しません。`.\Package.ps1`でDLL・ライセンス・導入スクリプト・検証記録をまとめます。

`DF557994A03C93D8BB4A14F80B1FBCC0FB29D547658442445D078D069BCDD9FE`


起動動画からの修正と検証範囲は [起動修正の記録](docs/Startup-repairs.ja.md) を参照してください。自然の操作ボタンは完了後も操作名を保持し、日英切り替えで結果も更新します。
